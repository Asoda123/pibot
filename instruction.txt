Якщо хочете запустити бота без проблем, використовуйте Docker. -> https://www.docker.com/
Для цього потрібно встановити WSL та Docker Desktop.


Використовуйте в терміналі
docker pull asoda123/pibot:final
Для завантаження на пристрій.

Посилання:
GitHub: https://github.com/Asoda123/pibot
Docker Hub: https://hub.docker.com/r/asoda123/pibot
